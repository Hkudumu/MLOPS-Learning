🔹 Traffic Management
	• Fine-grained traffic routing → Route traffic by version, headers, user identity, percentage (canary, A/B testing).
	• Fault injection → Simulate failures (delays, aborts) to test resilience.
	• Traffic mirroring (shadowing) → Send a copy of live traffic to a new service version for safe testing.
	• Outlier detection & circuit breaking → Automatically detect unhealthy instances and prevent cascading failures.
	• Retries & timeouts → Configurable request retries, failover, and response timeouts.
	• Load balancing → Multiple algorithms (round robin, random, least requests).

🔹 Security
	• mTLS (mutual TLS) → Encrypts pod-to-pod traffic automatically.
	• Identity & authentication → Uses SPIFFE IDs for workload identities.
	• Authorization policies (RBAC) → Fine-grained access control (e.g., “service A can call service B only on GET /api”).
	• Certificate management → Automatic key/cert rotation and distribution.
	• Zero-trust networking → Service-to-service communication is verified and encrypted by default.

🔹 Observability
	• Telemetry collection → Automatic metrics (latency, error rate, traffic volume).
	• Distributed tracing → Native integration with Jaeger/Zipkin/Tempo for request tracing.
	• Access & audit logging → Capture detailed logs of service-to-service calls.
	• Dashboards & monitoring → Rich visualization via Prometheus + Grafana integration.

🔹 Resilience & Reliability
	• Service discovery & dynamic routing → No need to hardcode endpoints; Istio discovers them.
	• Self-healing traffic flow → Removes unhealthy instances from routing automatically.
	• Global failover → Cross-cluster or multi-region routing.
	• Rate limiting & quotas → Control traffic flow per service or user.

🔹 Multi-Cluster & Multi-Network
	• Multi-cluster service mesh → Seamless service-to-service communication across Kubernetes clusters.
	• Mesh expansion → Extend Istio to run on VMs and bare metal (not just Kubernetes).
	• Federation → Connect multiple meshes while keeping them independent.

🔹 Extensibility
	• Envoy Filters → Custom traffic manipulation using Envoy proxy filters.
	• WebAssembly (Wasm) extensions → Add custom logic (auth, telemetry, transformations).
	• Integration with external systems → Works with external cert managers, policy engines, and identity providers.
